# Phase 8+ Technical Indicators venv (venvs/ta/)

#     communicates with this venv only via stdio JSON-RPC. Neither env
#     imports the other's packages.
#
# Setup: run scripts/setup_ta_venv.sh to create and populate this venv.
#
# Phase 8 trigger (from DJ-010): activate when > 6 indicators or > 50 tickers
# are required. The hifi.mcp.indicators_server module is then implemented to
# run in this environment.
#
